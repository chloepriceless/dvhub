Anlage koppeln

So läuft’s (die Anlage meldet sich bei uns — kein Portforwarding beim Kunden nötig):

  1. Appliance-ID holen: Beim Kunden unter Einstellungen → Status → „Installateurs-Portal“ ablesen (oder vom Kunden durchsagen lassen).
  2. Code erzeugen: ID unten eingeben — du bekommst einen 6-stelligen Kopplungs-Code.
  3. Zurück zur Anlage: Code + Portal-URL in die DVhub-Oberfläche eintragen (gleiche Kachel) und „Kopplung starten“ — die Anlage ruft uns an.
  4. Freigeben: Die Anfrage erscheint hier — einmal „Annehmen“ klicken, dann ist die Anlage live.
